3. Apply the exported review

Export tennis-calibration-review.json, then run the command below in the project folder. It creates a new replay and calibration desk, with the camera refitted and all landing geometry recomputed. No neural models are rerun.

.\Apply-Court-Review.ps1 -ReviewFile "$env:USERPROFILE\Downloads\tennis-calibration-review.json"

Use the actual exported filename if your browser adds “(1)”. Existing run folders and original court.yaml remain unchanged. Only explicit Confirm actions create confirmed bounce labels; a reviewed calibration alone does not confirm an event.
